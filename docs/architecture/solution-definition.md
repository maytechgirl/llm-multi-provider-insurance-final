# Definición de solución

## Problema

La aseguradora desea incorporar LLMs para asistir a agentes durante reportes de siniestros vehiculares. Antes de seleccionar un proveedor necesita evidencia comparable.

## Objetivo

Comparar tres alternativas —Ollama, OpenAI y Anthropic— ejecutando un conjunto controlado de prompts.

## Hipótesis

Un modelo puede presentar mejor calidad, pero mayor costo o latencia. La arquitectura debe permitir observar el trade-off y no asumir un ganador previamente.

## Alcance

- 8 prompts.
- 3 proveedores.
- 24 ejecuciones.
- métricas técnicas.
- evaluación de calidad.
- panel comparativo.

## Fuera de alcance

- decisión automática de cobertura;
- cálculo de indemnización;
- integración productiva con core de pólizas;
- uso de PII real;
- fine-tuning.
